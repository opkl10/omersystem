    אופן התרגום

    שפת המקור מזוהה אוטומטית. התרגום דורש חיבור לאינטרנט.

    תמלול אוטומטי יוצר כתוביות מסרטון שאין בו כתוביות. מנוע ברירת המחדל הוא ElevenLabs Scribe — המדויק ביותר, כולל עברית — ודורש מפתח API (חינמי).

    המפתח נשמר רק בדפדפן שלכם (localStorage) ונשלח ישירות ל-ElevenLabs בלבד. משיגים מפתח בחינם ב-elevenlabs.io › הגדרות › API Keys.

    שמות הדוברים

    זוהו הדוברים הבאים. הזינו שם לכל דובר ולחצו על ההחלה — השם יופיע בתחילת הכתוביות שלו.

    אחרי התמלול אפשר לעבור לטאב "תרגום" ולתרגם את התוצאה לכל שפה. נתמכים סרטונים ארוכים (עד שעה ויותר).

    לחיצה אחת מזהה את הרגעים השקטים ומוחקת אותם מהסרטון המיוצא — בלי שום כיוונון. הסף נקבע אוטומטית מרמות הקול של הסרטון, וקטעים שבהם יש כתוביות (דיבור) מוגנים ולא נחתכים. הסרטון המקורי לא נפגע.
