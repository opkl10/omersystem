# ◆ סטודיו הדפסה — מידול פשוט למדפסת תלת־ממד

כלי בדפדפן לעיצוב מוצרים בסיסיים להדפסה וייצוא קובץ STL — בלי התקנה, בלי שרת ובלי אינטרנט (כל הספריות בתיקיית `vendor`).

**הפעלה:** פותחים את `print3d/index.html` דרך שרת מקומי (`./start-server.sh` בתיקייה הראשית ← `http://localhost:8000/print3d/`), או ב-GitHub Pages תחת `/print3d/`.

## מה אפשר לעשות

- **מוצרים מוכנים עם מידות מתכווננות:** קופסה/מארגן עם תאים, מכסה תואם (עם מרווח התאמה), כוס/עציץ עם חור ניקוז, מעמד לטלפון, וו תלייה עם חורי ברגים, זווית L למדף, מחזיק מפתחות.
- **צורות בסיס:** תיבה (עם פינות מעוגלות), גליל, צינור/ספייסר, חרוט, כדור, חצי כדור, טורוס, טריז.
- **מידול חופשי (טאב "חופשי"):**
  - **שרטוט ומשיכה** — מציירים כל צורה דו-ממדית בעורך עם רשת והצמדה (הוספה, גרירה ומחיקה של נקודות, קווים מעוגלים, מידות חיות), והיא נמשכת לגוף בגובה שבוחרים, עם אפשרות להצרה כלפי מעלה.
  - **שרטוט וסיבוב** — מציירים חצי חתך והוא מסתובב סביב ציר: אגרטלים, ידיות, גביעים.
  - **ייבוא STL** — פותחים מודל קיים, משנים גודל, חותכים בו חורים או מחברים אליו חלקים.
- **טקסט תלת-ממדי** בעברית ובאנגלית (גופן Heebo), בולט או חרוט (מסמנים כ"חור").
- **קצוות מעוגלים או משופעים (פאזה)** לתיבות, לשרטוטים, לתגים ולטקסט — רק למעלה (מומלץ להדפסה) או למעלה ולמטה.
- **בחירה מרובה** (Shift/Ctrl + לחיצה, Ctrl+A): הזזה יחד, יישור לפי X/Y/Z, שכפול ומחיקה.
- **קבוצות עם פעולות בוליאניות:** חיבור (Ctrl+G), חיסור מהחלק הראשון, וחיתוך משותף. קבוצה נשארת ניתנת לעריכה ואפשר לפרק אותה (Ctrl+Shift+G).
- **קנה מידה ושיקוף** לכל חלק (גם בגרירה — מצב "גודל", מקש R), כולל היפוך כמו במראה.
- **שכפול במערך** — בשורה או במעגל (למשל 6 חורי ברגים סביב מרכז).
- **חורים:** כל צורה אפשר לסמן כ"חור" — היא תחוסר מהשאר (למשל גליל = חור לבורג).
- **הזזה וסיבוב** בגרירה בתצוגה (הצמדה למ"מ ול-15°), או במספרים מדויקים. סיבוב 90° בלחיצה + הנחה אוטומטית על המשטח.
- **בדיקות הדפסה:** חריגה מגודל המשטח, מודל מרחף/שקוע, דפנות דקות מדי ביחס לנחיר, שיפוע חד.
- **נתונים:** מידות, נפח, משקל משוער ואורך פילמנט.
- **ייצוא STL** (בינארי, כל החלקים מאוחדים לגוף אחד), שמירה/פתיחה של פרויקט JSON, שמירה אוטומטית בדפדפן, ביטול/חזרה.
- **הגדרות מדפסת:** גודל משטח, קוטר נחיר, מרווח התאמה, חומר.

## מבנה

| קובץ | תפקיד |
|---|---|
| `js/shapes.js` | קטלוג הצורות והמוצרים — פרמטרים ופונקציית בנייה לכל אחד |
| `js/sketch.js` | עורך השרטוט הדו-ממדי |
| `js/text.js` | טקסט: גופן, סדר כתיבה מימין לשמאל, המרה לצורות |
| `js/csg.js` | חיבור/חיסור גופים (three-bvh-csg) וחישוב נפח |
| `js/app.js` | ממשק, תצוגה תלת־ממדית, היסטוריה, ייצוא |
| `vendor/` | three.js r170, three-mesh-bvh, three-bvh-csg, opentype.js (MIT) |
| `fonts/` | Heebo (רישיון SIL OFL, ראה `OFL.txt`) |

**הוספת מוצר חדש:** מוסיפים רשומה ל-`CATALOG` ב-`shapes.js` עם `params` ו-`build(p, settings)` שמחזירה גאומטריה (ציר Z למעלה, ממורכזת ב-X/Y, יושבת על Z=0). הממשק נבנה ממנה אוטומטית.
