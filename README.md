# 🎬 מערכת כתוביות

עורך כתוביות מבוסס דפדפן — ללא התקנה, ללא שרת. פותחים את `index.html` ומתחילים לעבוד.

## יכולות

- **וידאו** — טעינת קובץ וידאו/אודיו מקומי עם תצוגה מקדימה חיה של הכתוביות. אפשר לעבוד גם בלי וידאו (שעון פנימי על רקע שחור).
- **תזמון** — עריכת זמני התחלה/סיום ידנית, כפתורי "התחלה=עכשיו" / "סיום=עכשיו", ציר זמן ויזואלי עם בלוקים לחיצים, וסמן זמן.
- **פונטים** — בחירה מפונטים מובנים או **העלאת קובצי פונט** (TTF / OTF / WOFF / WOFF2). פונטים שהועלו נשמרים בקובץ הפרויקט.
- **עיצוב** — גודל פונט, צבע טקסט, צבע ועובי מתאר, צבע ושקיפות רקע, מודגש/נטוי, מיקום אנכי על המסך.
- **מילים בשורה** — קביעת מספר מקסימלי של מילים בכל שורה (שבירת שורות אוטומטית, כולל בייצוא).
- **הדגשת מילים** — עוטפים מילה בכוכביות (`*מילה*`) והיא מקבלת צבע הדגשה מותאם והדגשה, גם בתצוגה וגם בייצוא (SRT: `<font color>`, VTT: `<b>`).
- **תמלול אוטומטי** — יצירת כתוביות מסרטון שאין בו כתוביות. מנוע ברירת המחדל: ElevenLabs Scribe (מדויק במיוחד בעברית, דורש מפתח API חינמי), עם חלופת Whisper שרצה כולה בדפדפן. בחירת חלוקה: מילה / 2 / 4 מילים / משפט.
- **נגישות** — ניווט מלא במקלדת (כולל חיצים בין הטאבים), תוויות לכל הפקדים, הכרזות סטטוס לקוראי מסך, ומצב מופחת-תנועה.
- **עיצוב גלובלי או פר-כתובית** — ברירת מחדל לכל הכתוביות, עם אפשרות לעיצוב מותאם לכתובית ספציפית.
- **אפקטים** — עמעום, מכונת כתיבה, החלקה מלמטה/מלמעלה, זום, קפיצה, זוהר, פעימה, רעידה, קשת צבעים — עם שליטה במשך אפקט הכניסה.
- **תרגום אוטומטי** — תרגום כל הכתוביות (או כתובית בודדת) ל-16 שפות עם זיהוי אוטומטי של שפת המקור. מצב החלפה או מצב דו־לשוני (מקור + תרגום). מבוסס Google Translate עם גיבוי MyMemory — דורש חיבור לאינטרנט.
- **ייצוא** — SRT ו-WebVTT (כולל מיקום אנכי ב-VTT).
- **הורדת הסרטון עם הכתוביות צרובות** — ייצוא וידאו (MP4/WebM) עם הכתוביות צרובות בתוכו, כולל כל העיצוב, ההדגשות והאפקטים — הכול בדפדפן, בלי תוכנת עריכה חיצונית. הייצוא רץ בזמן אמת (סרטון של דקה ייקח כדקה).
- **שמירה/טעינה של פרויקט** — קובץ JSON שכולל את כל הכתוביות, העיצובים והפונטים שהועלו.

## הפעלה על שרת מקומי במחשב

1. מורידים את הפרויקט: **Code ← Download ZIP** בעמוד הרפוזיטורי (או `git clone`)
2. מחלצים את ה-ZIP לתיקייה
3. **Windows:** לחיצה כפולה על `start-server.bat` (דורש [Python](https://python.org) מותקן)
   **Mac/Linux:** מריצים `./start-server.sh`
4. הדפדפן נפתח אוטומטית בכתובת `http://localhost:8000`

לחלופין אפשר פשוט לפתוח את `index.html` ישירות בדפדפן — בלי שרת בכלל.

## חיבור ElevenLabs (תמלול איכותי)

1. נרשמים בחינם ב-[elevenlabs.io](https://elevenlabs.io)
2. בחשבון: לוחצים על שם המשתמש ← **API Keys** ← **Create API Key** ומעתיקים את המפתח (`sk_...`)
3. במערכת: טאב **תמלול** ← מנוע **ElevenLabs Scribe** ← מדביקים את המפתח
4. המפתח נשמר בדפדפן בלבד ונשלח ישירות ל-ElevenLabs

## שימוש

1. פתחו את `index.html` בדפדפן (Chrome / Firefox / Edge).
2. טענו וידאו (אופציונלי).
3. הוסיפו כתוביות בטאב **כתוביות**, כוונו תזמון.
4. עצבו בטאב **עיצוב**, העלו פונטים בטאב **פונטים**.
5. ייצאו SRT/VTT או שמרו פרויקט להמשך עבודה.
