# 🎬 מערכת כתוביות

עורך כתוביות מבוסס דפדפן — ללא התקנה, ללא שרת. פותחים את `index.html` ומתחילים לעבוד.

## יכולות

- **וידאו** — טעינת קובץ וידאו/אודיו מקומי עם תצוגה מקדימה חיה של הכתוביות. אפשר לעבוד גם בלי וידאו (שעון פנימי על רקע שחור).
- **תזמון** — עריכת זמני התחלה/סיום ידנית, כפתורי "התחלה=עכשיו" / "סיום=עכשיו", ציר זמן ויזואלי עם בלוקים לחיצים, וסמן זמן.
- **פונטים** — בחירה מפונטים מובנים או **העלאת קובצי פונט** (TTF / OTF / WOFF / WOFF2). פונטים שהועלו נשמרים בקובץ הפרויקט.
- **עיצוב** — גודל פונט, צבע טקסט, צבע ועובי מתאר, צבע ושקיפות רקע, מודגש/נטוי, מיקום אנכי על המסך.
- **עיצוב גלובלי או פר-כתובית** — ברירת מחדל לכל הכתוביות, עם אפשרות לעיצוב מותאם לכתובית ספציפית.
- **אפקטים** — עמעום, מכונת כתיבה, החלקה מלמטה/מלמעלה, זום, קפיצה, זוהר, פעימה, רעידה, קשת צבעים — עם שליטה במשך אפקט הכניסה.
- **תרגום אוטומטי** — תרגום כל הכתוביות (או כתובית בודדת) ל-16 שפות עם זיהוי אוטומטי של שפת המקור. מצב החלפה או מצב דו־לשוני (מקור + תרגום). מבוסס Google Translate עם גיבוי MyMemory — דורש חיבור לאינטרנט.
- **ייצוא** — SRT ו-WebVTT (כולל מיקום אנכי ב-VTT).
- **שמירה/טעינה של פרויקט** — קובץ JSON שכולל את כל הכתוביות, העיצובים והפונטים שהועלו.

## שימוש

1. פתחו את `index.html` בדפדפן (Chrome / Firefox / Edge).
2. טענו וידאו (אופציונלי).
3. הוסיפו כתוביות בטאב **כתוביות**, כוונו תזמון.
4. עצבו בטאב **עיצוב**, העלו פונטים בטאב **פונטים**.
5. ייצאו SRT/VTT או שמרו פרויקט להמשך עבודה.

### קיצורי מקלדת

| מקש | פעולה |
|---|---|
| רווח | נגן / השהה |
| ← / → | דילוג 0.1 שנ' |
| Shift + ← / → | דילוג 1 שנ' |

## מבנה הקוד

```
index.html    — מבנה הממשק
css/style.css — עיצוב + אנימציות האפקטים
js/app.js     — לוגיקה: מצב, תזמון, רינדור, פונטים, ייצוא
```
